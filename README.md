# XOSS NAV+ ルート転送ツール

**ベータ版: 0.1.0-beta.1**

GPXを読み込み、XOSS NAV+用の `routebooks.json` と `Routes\*.ro` を作成して、USBマスストレージへ転送するWindows向けGUIツールです。

> **ベータ版に関する注意**
>
> 変換処理、XOSS NAV+実機への転送、本体でのルート表示までは確認済みです。実際にルート上を走行した際、正常に道案内されるかどうかはまだ確認できていません。大切なルートを転送する前に、必要に応じて手動バックアップを取り、少数のテストデータで動作を確認してください。

## 主な機能

- GPXのトラック（`trkpt`）またはルート（`rtept`）を読み込み
- ルート全体、始点、終点を表示する地図プレビュー
- ルート全長・点数・獲得標高の表示
- 指定距離を超えるルートの任意分割（分割なしも選択可能、分割時は連番RIDを付与）
- 出力点数上限による任意の間引き（1,000～24,000点、初期値15,000点）
- `routebooks.json` と `Routes\*.ro` の生成
- XOSS NAV+の既存ルートを保持した追記転送
- 端末内ルートの一覧表示と、複数削除（削除後は元に戻せません）

## 配布版の起動

1. 配布ZIPを展開します。
2. `XOSS_NAV_Route_Converter-v0.1.0-beta.1.exe` を起動します。
3. GPXを選択し、内容を確認してから保存またはXOSS NAV+への転送を行います。

配布版はPython不要の単体EXEです。Windowsのセキュリティ警告が表示された場合は、配布元とファイルのハッシュ値を確認したうえで判断してください。

## ソースから起動・ビルド

ソースから起動する場合は、Python 3.10以降とTkinterが必要です。Windows公式のPythonインストーラーでは通常Tkinterが含まれます。

```text
run_xoss_route_converter.bat
```

配布用EXEを作成する場合は、PyInstallerをインストールした環境で次を実行します。

```text
python -m pip install pyinstaller
build_exe.bat
```

`VERSION` の内容を使って、`dist\XOSS_NAV_Route_Converter-v0.1.0-beta.1.exe` が生成されます。

## 使い方

1. 「GPXを選択…」からGPXファイルを選択します。
2. 右側の地図プレビューでルート全体、始点、終点を確認します。「ルートに合わせる」、ズームボタン、マウスホイールを使えます。地図は左ドラッグで移動でき、マウスホイールの位置を中心にズームします。
3. ルート名を入力し、「分割する」を有効にした場合は1ルートあたりの上限距離を設定します。初期値は300 kmです。分割しない場合はチェックを外します。
4. 必要に応じて「点数による間引き」の出力点数上限を1,000～24,000点で入力します。初期値は15,000点です。元の点数が上限以下なら間引きません。間引き時も始点・終点は保持します。
5. 左側の分割プレビューで、全長、分割数、各区間の距離・出力点数・獲得標高を確認します。
6. XOSS NAV+をUSB接続し、`routebooks.json` のあるドライブを「再検索」します。
7. 「XOSS NAV+へ転送」を押し、確認ダイアログで続行します。

転送時は既存ルートを保持し、新しいRIDのルートを追記します。転送後は端末内ルート一覧を更新します。元に戻せるバックアップは作成しないため、必要な場合は事前に手動で保存してください。

地図背景はOpenStreetMapタイルを使用します。取得したタイルは一時フォルダにキャッシュされます。ネットワークに接続できない場合も、背景なしのルート線は表示できます。地図表示時はOpenStreetMapの利用規約と帰属表示に従ってください。

## 端末内ルートの削除

端末接続中は「端末内ルート管理」に既存ルートを一覧表示できます。複数選択して削除すると、バックアップを作成せずに `routebooks.json` と対象のROファイルを削除します。削除後は元に戻せないため、不要なルート以外を選択していないことを確認してから実行してください。

## 形式と制限事項

XOSS NAV+のRO形式は、公開されたGPX変換仕様ではありません。本ツールは同梱の `assets\xoss_nav_template.ro` を参照スキーマとして使用し、区間レコード数、区間ごとの座標点数、区間BBox、座標列オフセット、ELEV領域、ファイル長、経路・距離・標高・名前・CRCを再構成します。出力点数上限は1,000～24,000点で指定でき、距離に沿ってサンプルを縮約し、始点・終点を保持します。元の点数が上限以下の場合はGPXの点をそのまま出力します。区間レコードの点数フィールドは16bitのため、必要に応じて複数レコードへ分けます。

そのため、次の点に注意してください。

- 実機へのルート転送と本体でのルート表示は確認済みですが、走行時に正常に道案内されるかは未確認です。
- `routebooks.json` の形式やRO形式が将来のファームウェア更新で変わる可能性があります。
- USB転送中はXOSS NAV+を取り外さないでください。転送後は安全に取り外してください。
- XOSS NAV+が扱えるルート長・点数の公式上限は確認できていません。分割は任意に選択できますが、長大なルートは実機で表示と道案内を確認してください。
