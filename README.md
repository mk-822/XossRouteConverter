# XOSS NAV+ ルート転送ツール

**ベータ版: 0.1.0-beta.1**

GPXを読み込み、XOSS NAV+用の `routebooks.json` と `Routes\*.ro` を作成して、USBマスストレージへ転送するWindows向けGUIツールです。

> **ベータ版に関する注意**
>
> 変換処理と配布用EXEの確認は行っていますが、XOSS NAV+実機への転送後に本体でルートを表示・走行できることの確認はまだ十分ではありません。大切なルートを転送する前に、バックアップと少数のテストデータで動作を確認してください。

## 主な機能

- GPXのトラック（`trkpt`）またはルート（`rtept`）を読み込み
- ルート全体、始点、終点を表示する地図プレビュー
- ルート全長・点数・獲得標高の表示
- 指定距離を超えるルートの自動分割
- `routebooks.json` と `Routes\*.ro` の生成
- XOSS NAV+の既存ルートを保持した追記転送
- 転送前の `routebooks.json` バックアップ
- 端末内ルートの一覧表示と、バックアップ付きの複数削除

## 配布版の起動

1. 配布ZIPを展開します。
2. `XOSS_NAV_Route_Converter-v0.1.0-beta.1.exe` を起動します。
3. GPXを選択し、内容を確認してから保存またはXOSS NAV+への転送を行います。

配布版はPython不要の単体EXEです。Windowsのセキュリティ警告が表示された場合は、配布元とファイルのハッシュ値を確認したうえで判断してください。

## ソースから起動・ビルド

ソースから起動する場合は、Python 3.10以降とTkinterが必要です。Windows公式のPythonインストーラーでは通常Tkinterが含まれます。

```text
run_xoss_route_converter.bat
```

配布用EXEを作成する場合は、PyInstallerをインストールした環境で次を実行します。

```text
python -m pip install pyinstaller
build_exe.bat
```

`VERSION` の内容を使って、`dist\XOSS_NAV_Route_Converter-v0.1.0-beta.1.exe` が生成されます。

## 使い方

1. 「GPXを選択…」からGPXファイルを選択します。
2. 右側の地図プレビューでルート全体、始点、終点を確認します。「ルートに合わせる」、ズームボタン、マウスホイールを使えます。
3. ルート名と1ルートあたりの上限距離を設定します。初期値は300 kmです。
4. 左側の分割プレビューで、全長、分割数、各区間の距離・点数・獲得標高を確認します。
5. XOSS NAV+をUSB接続し、`routebooks.json` のあるドライブを「再検索」します。
6. 「XOSS NAV+へ転送」を押し、確認ダイアログで続行します。

転送時は既存ルートを保持し、新しいRIDのルートを追記します。元の `routebooks.json` は同じドライブに日時付きバックアップとして残します。転送後は端末内ルート一覧を更新します。

地図背景はOpenStreetMapタイルを使用します。取得したタイルは一時フォルダにキャッシュされます。ネットワークに接続できない場合も、背景なしのルート線は表示できます。地図表示時はOpenStreetMapの利用規約と帰属表示に従ってください。

## 端末内ルートの削除

端末接続中は「端末内ルート管理」に既存ルートを一覧表示できます。複数選択して削除すると、削除前に `XOSS_Backup_日時` フォルダへ `routebooks.json` と対象のROファイルを退避します。不要なルート以外を選択していないことを確認してから実行してください。

## 形式と制限事項

XOSS NAV+のRO形式は、公開されたGPX変換仕様ではありません。本ツールは同梱の `assets\xoss_nav_template.ro` を参照データとして使用し、XZRoutes v2の構造を保ったまま経路・距離・標高・名前・CRCを差し替えています。

そのため、次の点に注意してください。

- 実機でのルート一覧・ルート詳細・地図表示・走行時動作は、利用環境ごとに確認が必要です。
- `routebooks.json` の形式やRO形式が将来のファームウェア更新で変わる可能性があります。
- USB転送中はXOSS NAV+を取り外さないでください。転送後は安全に取り外してください。
- GPXの内容によっては、点数やルート長の制限により本体で扱えない場合があります。
